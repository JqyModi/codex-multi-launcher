# 订阅功能版本更新说明（发布草稿）

## 新增：订阅服务一键接入

本次更新新增“订阅服务”使用方式。创建 Profile 时不再需要寻找中转站、复制 API Key、填写 Base URL 或手动选择模型：完成登录、购买和设备授权后，App 会自动生成可直接使用的 Codex 配置。

### 使用方法

1. 点击左侧 `+` 创建 Profile。
2. 在“模型服务”中选择 `订阅服务`。
3. 点击 `前往授权`，在浏览器完成注册/登录、套餐购买和授权。
4. 返回 App，看到“授权已完成”后继续生成 Profile。
5. 点击 `打开` 开始使用。

[查看完整图文教程](https://jqymodi.github.io/codex-multi-launcher/subscription.html)

### 本次订阅功能包括

- 新用户注册后自动进入订阅购买流程。
- 已注册但未订阅的用户自动进入购买页。
- 已有有效订阅的用户可直接授权，不重复购买。
- 支付成功后自动恢复原授权会话并返回 App。
- 支持支付宝、微信支付和国际银行卡，实际可用方式以支付页为准。
- 为每台设备生成独立访问凭据，凭据加密保存在本机。
- 订阅 Profile 的接口地址、模型和凭据设为只读，避免误操作破坏授权。
- 支持订单主动查单、重复回调幂等和退款后同步撤销权益。

### 其他说明

- 原有 `API Key 配置` 和 `ChatGPT 账号登录` 模式保持不变，订阅服务是新增选项，不会影响已有 Profile。
- 套餐额度、有效期和 RPM 以购买页显示为准。
- 订阅服务需要联网使用；服务异常时可在 GitHub Issues 提交 App 版本、系统版本和诊断信息。
